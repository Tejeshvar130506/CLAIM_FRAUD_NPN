# Provider Risk Explainability & Interpretability Report

## Executive Summary

This report documents the interpretability layer implemented using **Explainable Boosting Machines (EBM)** to provide transparent, glass-box explanations for healthcare provider risk scoring.

The explainability layer enables medical auditors to understand both global model behavior and local provider-level risk factors, facilitating fair, defensible, and actionable audit decisions.

---

## 1. Interpretability Architecture: XGBoost vs EBM

To maintain statistical rigor and regulatory compliance, the system separates prediction modeling from interpretability modeling:

| Dimension | XGBoost Classifier (Production Model) | Explainable Boosting Machine (EBM) |
| :--- | :--- | :--- |
| **Role in Pipeline** | Primary Risk Score & Probability Predictor | Glass-Box Interpretability & Feature Attribution Model |
| **Model Nature** | Gradient Boosted Decision Trees (Ensemble) | Generalized Additive Model with Interactions (GAM) |
| **Primary Strength** | Maximum predictive accuracy (`0.9692` ROC-AUC) | 100% transparent feature shape functions & exact additive score components |
| **Audit Purpose** | Generates `fraud_probability` & `risk_score` | Generates local feature contributions & global feature rankings |

> [!WARNING]
> ### System Transparency Disclaimer
> 1. **Surrogate Model Separation**: EBM serves as an interpretable glass-box surrogate model. EBM does **not** directly expose or mirror the private internal tree split nodes of XGBoost.
> 2. **Potential Contributing Factors**: Feature flags generated by the system represent **"potential contributing factors"** for auditor review.
> 3. **No Single-Feature Proof**: No single feature or metric in isolation proves medical claims fraud. All flags require human audit verification.

---

## 2. Global Feature Importance (EBM Attributions)

The Explainable Boosting Machine ranks feature importance based on average absolute score contributions across all training providers:

1. `total_claim_amount` / `average_claim_vs_peer_average`: Financial reimbursement volume and state peer ratio divergence.
2. `inpatient_ratio` / `average_length_of_stay`: Inpatient admission frequency and prolonged stay duration.
3. `repeat_beneficiary_ratio` / `beneficiary_hhi_concentration`: Patient network concentration and repeat billing loops.
4. `same_attending_operating_ratio`: Co-occurring attending and operating physician billing flags.
5. `claims_per_month`: Temporal claim submission velocity.

## 3. Local Explanation & Case Study Example

### Case Study: Provider `PRV51069`
- **XGBoost Fraud Probability**: **`95.72%`**
- **Operational Risk Score**: **`96 / 100`**
- **Operational Risk Level**: **`CRITICAL`**

#### Potential Contributing Factors Highlighted:
- **Financial Billing Anomaly**: `total_claim_amount` is **3.0x higher** than state peer group averages.
- **Repeat Beneficiary Loop**: `repeat_beneficiary_ratio` is **61.7%** (over 60% of claims originate from repeat patients).
- **Physician Assignment Pattern**: `same_attending_operating_ratio` is **74.5%**.

## 4. Potential Coordinated Fraud Behavior Analysis

The explainability layer analyzes cross-provider relationships to detect **potential coordinated fraud behavior**:

1. **Shared Beneficiary Concentration**:
   - Multiple providers treating an overlapping cohort of high-frequency beneficiaries.
2. **Synchronized Billing Networks**:
   - Provider clusters exhibiting identical physician assignment ratios, high inpatient ratios, and parallel state peer deviations.

> [!NOTE]
> ### Terminology Constraint
> The system identifies **"potential coordinated fraud behavior"** for compliance investigations and does not assert claims of organized criminal activity.
